# P1-01I — Потоки страниц

Статус: draft для приёмки владельцем. Это design specification, не реализованный экран.

Проверочный макет: [`assets/P1-01I-assemble-dashboard.svg`](assets/P1-01I-assemble-dashboard.svg) — сборка панели из страниц. Макет выполнен только в светлой теме и содержит один экран.

## 1. Решение (O-027)

Страница — самостоятельная единица работы, как и в самом Zabbix, где страницу можно скопировать и вставить в другую панель. Пользователю не нужно тащить всю панель, чтобы взять одну страницу, и не нужно начинать с пустого листа, чтобы собрать панель из готовых страниц коллег или других панелей.

## 2. Сценарии

| Сценарий | Откуда | Куда | Результат | Этап |
|---|---|---|---|---|
| Взять страницу | страница панели в Zabbix (из снимка, только чтение), файл страницы, библиотека | — | черновик страницы с происхождением «Копия с сервера» или «Локальная» | дизайн P1-01I, реализация P4 |
| Добавить страницу в панель | черновик страницы или страница другой панели того же подключения | существующая панель в Zabbix либо локальный черновик панели | новая страница в целевой панели; существующие страницы не меняются | P5-03 (сервер), P4-09 (локально) |
| Собрать панель из страниц | любое сочетание: страницы панелей в Zabbix, локальные страницы, файлы страниц | новый черновик панели | панель из выбранных страниц в заданном порядке | P4-09, публикация P5-02 |
| Экспорт и импорт страницы | черновик страницы | файл `project/v2`, `kind: page` (O-026) | файл для обмена; импорт принимает несколько файлов сразу | P4-07, P1-03A |

## 3. Экран сборки панели

Композиция (макет):

1. Строка контекста: тип «Панель», происхождение «Локальная», состояние, режим.
2. «Страницы панели» — упорядоченный список: имя, источник (панель в Zabbix, локальная страница, файл), число виджетов, состояние строки («Привязки готовы», «2 связи изменены», «Нужны привязки»). Порядок меняется перетаскиванием и кнопками «вверх»/«вниз» (с текстовыми accessible names); «убрать» убирает страницу только из сборки.
3. «Добавить страницу из…» — меню источников: «Панель в Zabbix» (выбрать панель и одну её страницу), «Локальная страница» (черновики и библиотека), «Файл страницы» (можно несколько).
4. «Свойства панели» — официальные поля Zabbix: «Имя», «Период отображения страницы по умолчанию», «Запускать слайд-шоу автоматически».
5. «Проверка сборки» — итог по виджетам и страницам, переименованные связи, нерешённые привязки; основное действие — «Перейти к привязкам», вторичное — «Сохранить локально». Создание панели на сервере — только из раздела «Публикация» через проверенный план (P1-08).

## 4. Правила склейки

- **Связи виджетов (`reference`).** Значения должны быть уникальны в пределах панели. Zabbix 7.4.16 этого не проверяет: `dashboard.create` принимает одинаковые значения и на разных страницах, и на одной (P1-IN-04). Поэтому ZDashstitch переименовывает совпадающие значения вместе со всеми зависимыми виджетами и показывает, сколько связей изменено.
- **Привязки по каждой странице.** Страницы из разных источников ссылаются на разные узлы сети; соответствия разрешаются для каждой страницы отдельно (P1-05). Нерешённая обязательная привязка блокирует публикацию, но не локальное сохранение.
- **Страницы панелей шаблонов** ссылаются на элементы данных шаблона, а не узла сети, и в MVP не принимаются. Строка «Страница не добавлена» объясняет причину; панель-источник не меняется.
- **Источник не меняется.** Страница из Zabbix берётся из снимка в режиме «Только чтение»; ни сборка, ни публикация не изменяют панель-источник.
- **Имя новой панели** проверяется как подсказка; окончательный ответ даёт сервер (`dashboard_name_taken`, P2-06C).
- **Перенос страницы в существующую панель на сервере** — это изменение целевой панели (P5-03): полный набор существующих страниц передаётся без изменений, новая страница добавляется в конец либо в выбранную позицию.

## 5. Message IDs

Используются ID из P1-00F: `startup.action.assemble_dashboard`, `startup.action.take_page`, `startup.local.assemble_help`, `startup.local.take_page_help`, `library.section.pages`, `intent.assemble_dashboard`, `intent.take_page`, `intent.append_page`, `assemble.title`, `assemble.action.add_page`, `assemble.source.server`, `assemble.source.draft`, `assemble.source.file`, `assemble.reference.renamed`, `assemble.page.template_rejected`. Подписи свойств панели берутся из официальной русской локализации Zabbix.

## 6. Acceptance checks

- Со стартового экрана доступны «Собрать из страниц» и «Взять страницу».
- Одну страницу можно взять с панели на сервере без копирования всей панели.
- Панель собирается из страниц трёх разных источников; порядок страниц сохраняется.
- Совпадающие `reference` переименовываются вместе с потребителями; пользователь видит число изменённых связей.
- Привязки разрешаются по каждой странице; нерешённая обязательная привязка блокирует только публикацию.
- Страница панели шаблона отклоняется с понятной причиной.
- Файл одной страницы экспортируется и импортируется; импорт принимает несколько файлов.
- Ни один шаг не изменяет панель-источник.
