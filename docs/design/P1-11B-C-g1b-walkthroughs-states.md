# P1-11B/C — сквозные проходы и проверка состояний (проход G1b)

Статус: принято владельцем 25.10.2026 в составе шлюза G1b (решение H5).

Область: сценарии, не вошедшие в проход G1a ([`P1-11B-C-walkthroughs-states.md`](P1-11B-C-walkthroughs-states.md), проходы W1–W9 там не повторяются): редактор страницы, проверки и история (P1-04), синтетический предпросмотр, страницы и сборка панели (P1-01I), импорт файлов и шаблонов, библиотека, «Скопировать заново», экспорт и обезличивание (P1-07), преобразование копии в переносимый черновик, «Создать панель» / «Добавить страницу» / «Добавить виджеты» через «Публикацию», настройки (P1-09B–H), «О программе» (P1-12), правила Стежика (P1-10).

Метод: просмотр макетов (рендер Edge 1600×1000) вместе со спецификациями; сверка с фактами `backend_inputs_ru.md` P1-IN-01…11 и реестром возможностей P0-09 (`crates/zabbix/src/widget_capabilities.rs`). Экономия времени не оценивается (это P6-03).

## 1. Сквозные проходы (P1-11B)

Обозначения: «шаги» — экраны и действия пользователя; «выбор» — места, где пользователь принимает решение; «назад» — выход после ошибки; «Local» — сохранность локальной работы.

### W10. Автономно: новая панель, два виджета, автосохранение, отмена, повторное открытие

| # | Экран | Действие | Результат |

| 1 | «Начало» 01-01 | «Создать панель», имя | черновик `dashboard`, одна пустая страница |
| 2 | «Структура» 08-01 | «Изменить» страницу | редактор 12-01 |
| 3 | выбор виджета 12-02 | «График» → «В первое свободное место» | виджет «Нужно настроить», находка `widget_incomplete` |

Шаги: 7, выбор: 4. Назад: отпускание на занятое место возвращает виджет; неполная настройка не блокирует сохранение. Local: автосохранение, после сбоя — подсказка «Последние изменения могли не сохраниться» (P1-04G §4.6). Без каталога метрик — `draft.metrics.no_catalog` с путём «Импорт файлов» (P1-01D §5).

### W11. Ошибки композиции и переход к исправлению

Перекрытие при вставке размера, выход за сетку из импорта, пустое имя страницы → плашка «Проверки: N блокируют» → раздел «Проверки» (компоновка как 11-03) → «Перейти» → виджет выделен, фокус в поле инспектора. Шаги: 4, выбор: 1. Сохранение не блокируется ни одной находкой (P1-04F §2.1). Значения вне сетки из импорта не обрезаются молча — показываются находкой.

### W12. Копирование виджетов между страницами и черновиками

12-01 (ClickHouse, выбрать 3) → Ctrl+C → другой черновик, страница «Keeper и HAProxy» → Ctrl+V → 12-04: места заняты (предложены свободные), нет роли «ClickHouse» (добавить роль или «нужна привязка»), «Top queries» — тип только копированием, совпавший `reference` переименован → «Вставить 3». Шаги: 4, выбор: 3. Одна операция, Ctrl+Z отменяет всю вставку; источник не меняется; ID сервера не переносятся.

### W13. Синтетический предпросмотр

12-06: галка выключена по умолчанию → включить → метки «Синтетика» на каждом виджете, порог из подсказок предпросмотра, «Inserts*» — «нет данных для синтетики», «Disk usage» и «Top queries» — «Показано без данных». Выключить → генератор не вызывается. Шаги: 2, выбор: 1. Проверено по спецификации: синтетика не попадает в черновик, файлы, экспорт, журнал, диагностику и «Публикацию» (P1-04I-F).

### W14. Взять страницу и собрать панель

«Начало» → «Собрать из страниц» → 08-02: страница с сервера (снимок, только чтение), локальная страница, файл страницы → порядок, свойства панели, «2 связи переименованы» → «Перейти к привязкам» по каждой странице. Страница панели шаблона — «Страница не добавлена» с причиной. Шаги: 6, выбор: 4. До P0-10 страница с виджетами вне `graph`/`item_value` в переносимую сборку не помещается — причина видна (O-034, P1-01D §5).

### W15. Импорт файлов: пакет, страница, экспорт шаблонов, старый формат, опасный ZIP

02-02: пять файлов, распознанный вид и «Станет» по каждому; `old-dashboards.yaml` блокирует запуск до выбора корня; `evil-package.zip` отклонён уже при проверке (`relative_path`) → «Импортировать» → 02-03: 3 импортированы, 1 частично (панели шаблонов), 1 отклонён → «В библиотеку» → 04-01. Шаги: 5, выбор: 2. Каждый файл сохраняется целиком или никак; отклонённый ничего не меняет.

### W16. Шаблоны с сервера в библиотеку

03-02: группа, поиск, три шаблона (один уже есть — новая версия) → «Импортировать в библиотеку (3)» → прогресс (экспорт шаблона до 3,9 с при первом вызове, P1-IN-06) → 04-01: версии каталога, «Используют», удаление используемого недоступно. Пустой экспорт без ошибки → «не найдено или нет доступа», каталог не создаётся (P1-IN-08). Шаги: 4, выбор: 2.

### W17. «Скопировать заново» с переигрыванием правок

07-01 «Проверить источник» → `conflict` → «Скопировать заново» → 07-02: 9 применились, 1 конфликт («Оставить серверное» / «Применить моё»), 1 цель исчезла («Убрать правку») → «Принять новую базу» после решений; «Вернуться к прежней базе» без потерь. Шаги: 5, выбор: 3. Молчаливого слияния нет; сервер не меняется.

### W18. Экспорт: переносимый и обезличенный

02-01 «Экспорт в файл…» → 13-01: цель «Наружу» (доверенный перенос недоступен, O-011), состав, «Не входит никогда», совместимость «7.4.0+ (вычислено)» → 13-02: 7 находок, решения (роль, псевдоним, «убрать виджет», «оставить»), обязательный флажок «пакет не гарантированно обезличен» → нативный диалог или скачивание → 13-03: файл, SHA-256, принятые предупреждения. Шаги: 5, выбор: 4. Черновик не меняется; повтор экспорта предлагает прошлый режим.

### W19. Копия с сервера → переносимый черновик → экспорт

02-01 «Сделать переносимой для экспорта…» → 13-04: вся панель, имя нового черновика, отчёт преобразования → «Создать переносимый черновик» → «Проверки» нового черновика (неперенесённое видно) → W18. Шаги: 4, выбор: 2. Копия, её снимки и привязки не меняются; происхождение `server_snapshot` без адреса и ID. **Расхождение с данными — находка M10.**

### W20. «Создать панель», «Добавить страницу», «Добавить виджеты» через «Публикацию»

- **Создать панель** из локального черновика или сборки: «Чтение-запись» (05-04) → «Привязки» по ролям → «Публикация» 11-01 (как для клона: имя, владелец и доступ; до P5-08 — личная) → 11-03 → 11-04 (только «Мои изменения»: всё «добавлено») → 11-06 (`dashboard.create`) → 11-07 / 11-08 (сверка по имени и отпечатку).
- **Добавить страницу** из черновика страницы: «Назначение» — выбор существующей панели подключения → 11-03 (права на запись цели, свежесть цели) → 11-04 (новая страница «добавлено», остальные «без изменений» с ID) → 11-06 (`dashboard.update` со всеми страницами) → 11-07.
- **Добавить виджеты**: вставка (W12) в рабочую копию → те же шаги с целевой страницей.

Шаги: 7–8, выбор: 3–4. Назад: каждая блокировка ведёт в свой шаг (P1-01F §5). Операции подтверждены P1-IN-04: `dashboard.create` с умолчаниями, Append страницы и виджетов с сохранением ID. **Находки M11–M13** касаются того, что лабораторией не подтверждено.

### W21. Настройки: файл с ошибкой, перенос хранилища, завершение сессии, диагностика, «О программе»

06-02 (ошибки файла, резервные копии, «Заменить файл верными настройками…») → 06-03 (новое место — локальный диск, проверки, несохранённый черновик блокирует перенос, «Перенести данные сюда») → 06-05 («Завершить сеанс», недоступно во время записи) → 06-06 (пакет для поддержки с предпросмотром, адреса серверов только по флажку) → 06-04 (версия, лицензии, сайт — GitHub). Шаги: 5, выбор: 4. Хранилище не удаляется и не подменяется тихо (S-2, S-3).

### W22. Стежик по всем проходам

Сверено с 00-02 и P1-10C: wave — пустые «Черновики» (W10 до первого черновика); chart — этапы дольше 2 с (W15, W16, копирование); compare — пустые «Привязки»; inspect — «Проверки» без находок (W11 после исправления); success — после «Проверено повторным чтением» / «Сверено: записано» (W20). Нигде нет персонажа в ошибках, конфликте, неизвестном итоге, подтверждениях, редакторе, таблицах и вводе секретов. Нарушений не найдено.

Итого проходов: 13 (W10–W22).

## Проверки приёмки

- Все сценарии G1b пройдены по экранам с возвратом после ошибки; локальная работа нигде не теряется молча.
- Каждый экран G1b имеет состояния загрузки, пустоты, частичности, отказа и повтора там, где они применимы; пробелы перечислены.
- Ни один экран не обещает возможность API, не подтверждённую лабораторией, без блокировки в «Проверках» или «Публикации» — кроме M10–M13, которые нужно закрыть до реализации соответствующих задач.
- Синтетика, Стежик, экспорт и настройки не нарушают правил безопасности данных (секреты, ID, адреса).
