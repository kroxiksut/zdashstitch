# P1-04I — предпросмотр с синтетическими данными (O-028)

Статус: принято владельцем 25.10.2026 (решения E-1…E-4, G-1…G-3, I-1…I-4 по рекомендации). Это design specification, не реализованный экран. Реализация — P4 (предпросмотр «Структуры» и редактора P4-03); генератор — `application`.

Входы: O-028 (синтетика только по галке и с меткой; реальные данные — ROADMAP F-08), P1-01B §2a «Предпросмотр страницы» (принятый макет 08-01: галка «Показать синтетические данные», метка «Синтетика»), P1-01D §5, P1-IN-05 (экспорты шаблонов), P1-IN-10 (виджеты и поля 7.4), P0-09 (реестр возможностей), `schemas/metrics-v1.schema.json`, P1-00C (токены), P1-00F.

Макет (только светлая тема, генератор `docs/design/tools/synthetic_svg.py`):

| Файл | Подзадача | Экран |
|---|---|---|
| `12-editor/12-06_P1-04I_synthetic-preview.svg` | P1-04I-A…E | предпросмотр страницы «ClickHouse» черновика «Базы данных: сводная» с включённой синтетикой: графики с рядами, значение элемента данных, ряд «нет данных для синтетики», карточки без данных, основания по виджетам, обозначения |

Синтетика — иллюстрация компоновки, а не данные. Она никогда не выдаётся за значения из Zabbix и не попадает в черновик, файлы, экспорт, журналы, диагностику, отчёты и экраны публикации.

## P1-04I-A — переключатель и маркировка

- Галка «Показать синтетические данные» (`draft.preview.synthetic.toggle`) — над предпросмотром страницы в «Структуре» (08-01) и в редакторе (P1-04A). По умолчанию выключена.
- Состояние галки — настройка вида текущей вкладки, а не данные черновика: не сохраняется в черновик, не переносится между черновиками и после перезапуска снова выключена (P1-01D §5).
- Выключена: каждый виджет — каркас с именем и типом (как в 08-01 до включения); генератор не вызывается.
- Включена: у каждого виджета с синтетическими значениями — метка «Синтетика» (`draft.preview.synthetic.badge`) в правом верхнем углу; под предпросмотром — пояснение `draft.preview.synthetic.notice`. Метка и пояснение не скрываются при любом масштабе и ширине экрана.
- Подписи осей и легенды показывают единицы из каталога; числа форматируются по языку интерфейса.
- Копирование и снимок предпросмотра (если появятся) сохраняют метки и пояснение: синтетика без метки наружу не выходит.
- Для экранного диктора у каждого виджета с синтетикой accessible description `draft.preview.synthetic.a11y` («синтетические значения, не данные Zabbix»); график без синтетики описывается как каркас.

## P1-04I-B — входные данные генератора

| Вход | Откуда | Если нет |
|---|---|---|
| Тип значения (`numeric_float`, `numeric_unsigned`, `character`, `text`, `log`, `binary`) | каталог метрик `metrics/v1` (обязательное поле) | ряд — «нет данных для синтетики» |
| Единицы (`units`) | каталог метрик (обязательное поле, может быть пустым) | форма по типу значения без единиц |
| Сопоставление значений (value map) | подсказки предпросмотра в библиотеке (см. решение 1) | значение без подстановки текста |
| Пороги триггеров | подсказки предпросмотра: только простые пороги вида «последнее значение больше/меньше константы или макроса» | линия порога не рисуется |
| Значения пользовательских макросов | подсказки предпросмотра: значение по умолчанию на уровне шаблона; значения узлов сети офлайн неизвестны | порог с нераскрытым макросом не рисуется |
| Интервал обновления | подсказки предпросмотра | шаг по ограничению числа точек (P1-04I-D) |
| Период времени | поле виджета «Период времени» или период панели по умолчанию | 1 час |

Источник метрики виджета: для переносимого черновика — ссылка «каталог + метрика»; для копии с сервера — метаданные элементов данных, на которые ссылается снимок (решение 4). Для строкового шаблона элементов (`svggraph` `ds.N.items`) ряд строится по каждой метрике каталога, имя которой совпадает с шаблоном по правилам Zabbix 7.4 (видимое имя, без учёта регистра, только `*`); совпадений нет — «нет данных для синтетики».

Честная заглушка: если для ряда или значения не хватает типа значения или метрика не найдена в каталоге, вместо кривой — текст «Нет данных для синтетики» (`draft.preview.synthetic.no_data`) и причина в подсказке (`draft.preview.synthetic.no_data.reason.*`). Генератор не придумывает метрику, единицы и форму.

## P1-04I-C — диапазоны и формы значений

| Тип значения / единицы | Диапазон | Форма |
|---|---|---|
| `%` | 0–100 | ровная волна около середины диапазона ниже порога, редкие всплески |
| `B` (байты) | порядок величины по порогу, если есть; иначе 10⁸–10¹⁰ | медленный дрейф; для «свободно/доступно» — пила с плавным спадом |
| `bps`, `Bps` | ≥ 0; порядок 10⁵–10⁸ | суточная волна плюс шум; никогда не отрицательно |
| `s` | ≥ 0; доли секунды – десятки секунд | задержки: малое основание с редкими пиками |
| `uptime` | от 1 суток | монотонный рост на длину периода |
| `unixtime` | текущее время | значение = момент точки |
| счётчик в секунду (`ops`, `rps`, `qps`, `/s`) | ≥ 0 | волна плюс шум |
| `numeric_unsigned` без единиц | ≥ 0, целые | медленный дрейф, только целые |
| `numeric_float` без единиц | около 1 | волна; для нагрузки (`load`) — 0–4 |
| value map | только состояния из карты | ступеньки; большую часть времени «нормальное» (первое значение карты, если не задано иное), редкие переходы |
| `character`, `text`, `log` | — | только виджет «Значение элемента данных»: короткая нейтральная строка `draft.preview.synthetic.sample_text`; без реальных имён, адресов и сообщений журналов; графики для этих типов — «нет данных для синтетики» |
| `binary` | — | «нет данных для синтетики» |

Пороги: если порог известен, синтетика большую часть времени держится по безопасную сторону порога и пересекает его не более одного раза за период, чтобы линия порога была видна в контексте. Значение никогда не выходит за физически возможный диапазон единиц.

## P1-04I-D — время и детерминированность

- Ось времени — «Период времени» виджета или период панели; без него — последний час. Время показывается относительно «сейчас», в часовом поясе интерфейса.
- Шаг — интервал обновления метрики; если точек больше лимита — шаг увеличивается: не больше 300 точек на ряд и 2000 точек на виджет.
- Зерно генератора — от **устойчивого локального идентификатора страницы**, идентификатора виджета, номера набора данных и ключа метрики (или слота узла сети). Одна и та же страница даёт одинаковую картинку на любой машине; изменение одного виджета (его полей или положения) не меняет картинку остальных.
- Генератор — детерминированный ГПСЧ с фиксированным алгоритмом и версией (`synthetic_rules_version`); смена правил меняет версию, и тесты эталонных картинок обновляются явно.
- Генерация ленивая: только для видимых виджетов и только при включённой галке.

## P1-04I-E — охват типов виджетов

| Тип | При включённой галке |
|---|---|
| «График» (`svggraph`) | ряды по наборам данных; легенда — имя метрики и узел (роль или слот для переносимого черновика), метка «Синтетика»; линия порога, если известна; ряд без данных — строка легенды «нет данных для синтетики» |
| «График (классический)» (`graph`) | как `svggraph` по элементам графика |
| «Значение элемента данных» (`item`) | одно значение, единицы, при value map — текст состояния; цвет порога только если порог известен |
| Остальные известные реестру типы (`clock`, `problems`, `problemsbysv`, `hostavail`, `systeminfo`, `tophosts`, `gauge` и другие из P1-IN-10) — до решения O-030 | карточка без данных: тип и ключевые настройки (`draft.preview.card.no_data`); метки «Синтетика» нет, потому что синтетики нет |
| Тип, неизвестный реестру | каркас с именем и пометкой «Изменение не поддерживается» (`common.state.edit_unsupported`) |

Часы (`clock`) показывают реальное локальное время компьютера — это не данные Zabbix и не синтетика, метки нет.

## P1-04I-F — handoff и проверки

**Где работает генератор.** В `application` (Rust), отдельным модулем предпросмотра: на вход — черновик (только чтение), каталоги, подсказки предпросмотра и параметры вида (страница, ширина экрана, период); на выход — `SyntheticPreview` для видимых виджетов: ряды точек, единицы, пороги, метки и причины «нет данных». Тип ответа отдельный от данных черновика и не сериализуется ни в один формат хранения или экспорта. UI только рисует.

| Команда | Предусловия | Успех | Ошибки |
|---|---|---|---|
| `preview.synthetic.render` | галка включена; страница открыта | `SyntheticPreview` для указанных виджетов | `preview.synthetic.no_catalog` (нет каталогов — все ряды «нет данных») |

Правила с примерами. Ключи и макросы шаблонов ниже — по известным официальным шаблонам Zabbix 7.4; помеченные «сверить» проверяются по экспортам лаборатории P1-IN-05 при реализации, правила от этого не зависят.

| Шаблон | Метрика (пример) | Тип / единицы | Правило |
|---|---|---|---|
| Linux by Zabbix agent | CPU utilization, `system.cpu.util` | `numeric_float` / `%` | 0–100, волна ниже порога триггера `{$CPU.UTIL.CRIT}` (по умолчанию 90 — сверить) |
| Linux by Zabbix agent | System uptime, `system.uptime` | `numeric_unsigned` / `uptime` | монотонный рост |
| Linux by Zabbix agent | Available memory, `vm.memory.size[available]` | `numeric_unsigned` / `B` | дрейф в пределах порядка памяти |
| Linux by Zabbix agent | Interface in, `net.if.in["{#IFNAME}"]` (LLD) | `numeric_unsigned` / `bps` | суточная волна; экземпляр LLD — по каталогу или «нет данных» |
| Linux by Zabbix agent | Zabbix agent ping, `agent.ping` | `numeric_unsigned` / value map | ступенька «Up» (сверить имя карты) |
| PostgreSQL by Zabbix agent 2 | активные соединения (сверить ключ) | `numeric_unsigned` / без единиц | целые ≥ 0, дрейф |
| PostgreSQL by Zabbix agent 2 | время работы сервера (сверить ключ) | `numeric_float` / `uptime` | монотонный рост |
| PostgreSQL by Zabbix agent 2 | размер базы (LLD, сверить ключ) | `numeric_unsigned` / `B` | медленный рост |
| ClickHouse by HTTP | запросы в секунду (сверить ключ) | `numeric_float` / `rps` | волна плюс шум, ≥ 0 |
| ClickHouse by HTTP | время работы (сверить ключ) | `numeric_float` / `uptime` | монотонный рост |
| ClickHouse by HTTP | доступность порта (сверить ключ и карту) | `numeric_unsigned` / value map | ступенька «доступен» |

**Решения владельца** (рекомендация — первый вариант):

1. **Где взять value maps, пороги, макросы и интервал.** Каталог `metrics/v1` хранит только тип значения и единицы. Рекомендация: при импорте шаблона (файл или экспорт конфигурации) сохранять рядом с каталогом **локальные подсказки предпросмотра** (value maps, простые пороги с макросами по умолчанию, интервал) в библиотеке, только на этом компьютере и не в переносимых файлах; переносимые черновики у получателя показывают синтетику по типу и единицам. Альтернатива — новая версия формата каталога (изменение схемы).
2. **Зерно генератора.** В тексте P1-04I-D зерно — «от отпечатка страницы»; отпечаток содержимого меняется при любой правке и перерисовал бы все виджеты, что противоречит тому же пункту. Рекомендация: устойчивый локальный ID страницы + ID виджета + номер набора + ключ метрики (принято в этой спецификации).
3. **Где работает генератор.** Рекомендация: `application` (Rust), чтобы правила и детерминированность проверялись тестами в одном месте; UI только рисует.
4. **Метаданные элементов данных для копий с сервера.** Снимок панели содержит ссылки на элементы данных по ID, а тип значения и единицы — нет. Рекомендация: при копировании (P2-05) читать `item.get` для ссылок снимка и хранить тип, единицы и value map как локальные метаданные копии (только чтение, не экспортируются). Без этого синтетика для копии — «нет данных».

## Проверки приёмки

- Галка по умолчанию выключена и не сохраняется в черновик; при выключенной галке генератор не вызывается (тест на счётчик вызовов).
- Каждый виджет с синтетикой имеет метку «Синтетика»; под предпросмотром — пояснение; при копировании и снимке метки сохраняются.
- Синтетика отсутствует в сохранённом черновике, файлах `project/v2`, пакетах ZIP, журнале операций, диагностике, отчётах и на всех экранах «Публикации» (отрицательные тесты по каждому месту).
- Одна и та же страница даёт одинаковые ряды на разных машинах; правка одного виджета не меняет ряды других (эталонный тест).
- Нет типа значения или метрики — «Нет данных для синтетики» с причиной, а не выдуманная кривая.
- Значения не выходят за диапазон единиц; value map даёт только состояния карты; лимиты точек соблюдаются.
- Неизвестный тип — каркас «Изменение не поддерживается»; известные типы без синтетики — карточка с типом и настройками.
