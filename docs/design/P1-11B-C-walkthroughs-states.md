# P1-11B/C — сквозные проходы, состояния и данные лаборатории

Статус: проход G1a принят владельцем 25.10.2026 (решения D1—D7 по рекомендации P1-11H). Версия: **G1a v1, 25.10.2026**. Проход выполнен по принятым макетам `docs/design/assets/**` (просмотрены рендером в Edge) и спецификациям P1-00E/F, P1-01A–I, P1-02, P1-03, P1-05, P1-08, P1-09B/C, P1-12, P1-IN-01–11 (`backend_inputs_ru.md`). Экономия времени не оценивается (P6-03).

Объём G1a: сценарии P2–P3 — автономное открытие и правка, подключение «Только чтение», копия панели с сервера, замена узла сети 1 → 1, клон 2 → 3, «Сохранить копию», публикация с повторным чтением, неизвестный итог, конфликт, восстановление после перезапуска, а также пустые, частичные, запрещённые и неподдерживаемые пути. «Собрать из страниц», «Добавить страницу/виджеты», импорт и экспорт файлов — G1b; здесь только отмечены.

Обозначения: **М** — есть макет; **С** — состояние описано в спецификации (общие компоненты P1-00D/E, без отдельного макета); **—** — не применимо; **Пробел** — не определено.

## Проверки приёмки

- Каждый сценарий G1a пройден по принятым экранам; у каждой ошибки есть выход, локальная работа сохраняется.
- Каждый факт P1-IN-01–11, нужный G1a, учтён экраном или состоянием; расхождения перечислены как находки.
- Ни один экран не обещает записи сверх подтверждённого лабораторией без пометки.
- Находки M1–M3 закрыты или приняты владельцем до решения G1a (P1-11H).
