# Z80-P1-03 — тексты и состояния для Zabbix 8.0

17.11.2026. Это handoff к P1-03 (импорт), P1-02 (подключение), P1-05 (маски) и P1-09G (диагностика), а не заявление о реализованной поддержке 8.0. Основа — [Z80-P1-01](Z80-P1-01-api-roles-ru.md) и [Z80-P1-02](Z80-P1-02-widgets-lld-formats-ru.md). Точный patch и разрешённая лаборатория 8.0 неизвестны. Серверный адаптер 8.0 и его реестр виджетов пока закрыты; экспорт шаблонов 8.0 текущий parser отклоняет кодом `template_export_version`.

| Место | Видимое состояние и message IDs | Доказательство / граница |
|---|---|---|
| Файловый импорт шаблонов | `template_import.help`, `template_import.source_steps` явно предлагают экспорт **7.4** и предупреждают, что 8.0 эта сборка не импортирует. Отказ остаётся структурированным кодом в `template_import.rejected`; показ имени файла не означает успешного разбора. | `template_import::EXPORT_VERSION = "7.4"`; до отдельного parser/fixture/lab контракта не обещать YAML/JSON/XML 8.0. Штатный экспорт глобальной панели 8.0 не равен экспорту шаблона и не равен переносимому `project/v2`. |
| Импорт переносимого пакета | `package_import.compatibility_*` — диапазон, заявленный автором. `package_import.registry_*` и `draft.compat.label` — **локальная оценка формата** по текущему 7.4 реестру, не серверная возможность 8.0 или разрешение публикации. При unknown/incompatible нельзя повышать статус по одному номеру версии. | `crates/zabbix/src/widget_capabilities.rs` имеет 7.4 registry и пустой 8.0 registry. Индивидуальные read/edit/create/copy gates проверяются позже по типу и операции. |
| Подключение и диагностика | `errors.connection.version_unsupported` сообщает, что у сборки нет серверного адаптера для полученной версии, и предлагает автономную работу. `apiinfo.version` — отдельная стадия до учётных данных; обнаружение номера API не равно входу, доступу к объектам или write authority. В будущей P1-09G диагностике показывать версию, стадию и безопасный код; точный текст `error.data` и секреты не включать. | Z80-P1-01: ошибки 7.4.16 и правила роли не переносятся на 8.0. Новых кодов или запроса к серверу эта задача не вводит. |
| Предпросмотр масок клона и переносимой страницы | `clone.pattern.scope/count`, `portable_review.help/matches` называют только видимые совпадения на выбранных узлах. Иные узлы Zabbix могут также совпасть; ограниченная видимость аккаунта не доказывает отсутствие других совпадений. Подтверждение переносимой маски временное, публикацию не разрешает. | Существующие preview/count вычисляются из ограниченного набора целевых узлов. Правила масок из P1-IN-04 проверены лишь для 7.4.16; перед утверждением поведения 8.0 нужны разрешённая лаборатория и отдельные проверки host/item pattern, регистра, `*`, скрытых узлов и изменения данных между preview и publish. |

EN — исходные строки в `lang/en/`, RU — парные строки в `lang/ru/`; технические идентификаторы и подстановки не переводятся. Общие компоненты и утверждённые потоки P1 не менялись. Генерируемый `ui/src/lib/i18n/generated.ts` обновляется из каталогов. `configuration.import` остаётся вне allowlist, и новые тексты не открывают ни одну 8.0 capability.

Для приёмки 8.0 позднее нужны точный patch, отрицательные файлы экспорта 8.0, безопасная классификация отказа в UI, роль/видимость для масок и version-bound проверки каждого поддержанного действия. Пока эти доказательства отсутствуют, handoff сохраняет состояние «не поддерживается этой сборкой».
