Статус: проход G1a принят владельцем 25.10.2026 (решения D1—D7 по рекомендации P1-11H). Версия: **G1a v1, 25.10.2026**. ## 4. Локализация

**Дубли ID.** Нет: каждый из 628 ID определён один раз.

**Плейсхолдеры.** Совпадают во всех парах EN/RU.

**ICU plural.** `library.delete.in_use` (P1-03, строка 217): в RU только `one/other`, нужны `few/many` (F-04).

**Один смысл под разными ID** (рекомендуется оставить один, второй сделать ссылкой или удалить до переноса в `lang/`):

| Оставить | Убрать или сослаться | Текст |
|---|---|---|
| `server.action.copy` (P1-03) | `dashboards.action.import_snapshot` (P1-00F) | «Скопировать с сервера» |
| `profiles.title` (P1-00F) | `library.section.profiles` (P1-03) | «Профили оформления» |
| `profiles.blueprints.title` (P1-00F) | `library.section.blueprints` (P1-00F) | «Заготовки виджетов» |
| `publication.target.name` (P1-08) | `clone.new_name` (P1-00F) | «Имя новой панели» |
| `startup.dialog.browser_fallback` (P1-00F) | `import.files.upload` (P1-03) | «Загрузить через браузер» |
| `common.state.offline` (P1-00F) | `draft.context.offline` (P1-01B) | «Автономно» |

Остальные 13 совпадений («Структура», «Привязки», «Проверки», «Область», «Версия» и т. п.) — разные места интерфейса с одинаковым словом; их стоит сохранить раздельно, чтобы перевод на другие языки мог различаться.

**Глоссарий.** Официальные термины Zabbix в видимых строках соблюдены: «хост», «айтем», «дашборд» не встречаются. Нарушения: `bindings.fitness.read_only` (P1-00F, строка 193) — «Распознано, но доступно только для чтения» при правиле P1-00E §12 «Только чтение — только режим подключения» (F-03); «проект» в `about.license.zabbix_note` и `about.docs.website` (P1-12) (F-05).

**Команды и сообщения в одном пространстве имён.** Таблицы handoff используют имена команд API в тех же префиксах, что и message IDs (`publication.confirm` и `publication.confirm.title`, `connection.enable_writes` и `connection.enable_writes.title`, `settings.reload`). Для вложенных каталогов `lang/` это конфликт «ключ одновременно лист и узел» (F-14).

**Строки макетов без ID.** Совпадают с ID 861 узел; без ID — заголовки колонок и разделов (≈150: «ИСТОЧНИК (БАЗА)», «ЧТО БУДЕТ», «СОВПАДЕНИЕ»…), кнопки мастеров и панели действий («Назад», «Далее: проверки/изменения/подтверждение/новый узел/соответствия/серии/итог», «Сохранить черновик», «Подтвердить запись…», «Вернуться к черновику», «К черновикам», «Ещё файлы»), фильтры-счётчики («Все 19», «Изменены 11»), подсказки полей поиска, метки прав получателей «Только чтение»/«Чтение-запись», подписи состояния строк («Привязки готовы», «Нужны привязки», «ждёт проверки»). Остальное — данные сценария и пояснительный текст, который в спецификациях выражен ID (F-02).
