# Правила проверочных макетов

Статус: рабочее правило дизайна P1 от 25.10.2026. Нормативные основы — `AGENTS.md` (раздел 4), O-024, P1-00B—P1-00H; при расхождении действуют они.

## Что рисуется

- Только русский язык и только светлая тема; один экран — один SVG. Английские строки и их длина проверяются в P1-00F и тестах P2-00, тёмная и системная темы — по semantic tokens и в runtime.
- Термины — по официальной русской локализации Zabbix и глоссарию P1-00F. Слово «проект» в интерфейсе не используется. «Только чтение» — только режим подключения; для виджета, который ZDashstitch не изменяет, — «Изменение не поддерживается».
- Синтетические данные — только по галке и с меткой «Синтетика» (O-028).
- Состояния, которые отличаются одной плашкой или текстом, описываются таблицей в спецификации, а отдельный SVG получает только экран с другой компоновкой.

## Холст и шапка

- `viewBox="0 0 1600 1000"` (длинные справочники — та же ширина), у корневого `<svg>` нет фиксированных пикселей: `width="100%"`.
- Шрифт — системный стек `system-ui, -apple-system, "Segoe UI", sans-serif`; моноширинный — `ui-monospace, "Cascadia Mono", Consolas, monospace`.
- Шапка 72 px на каждом экране: логотип, глобальная навигация «Начало / Черновики / Панели в Zabbix / Библиотека / Подключения», метка режима подключения, кнопка «Настройки». Генерируется `tools/appbar.py`, вручную не рисуется.
- Рабочая область черновика: боковая колонка 260 px («Обзор / Структура / Привязки / Проверки / Публикация», затем «Происхождение»), над заголовком хлебные крошки, справа от заголовка локальный статус.

## Цвета макетов

| Роль | Значение |
|---|---|
| Фон страницы / карточки | `#f5f7fb` / `#ffffff`, рамка `#d0d5dd`, разделитель `#e4e7ec` |
| Текст / вторичный текст | `#17213a` / `#667085` |
| Основное действие, выбранное | `#3156a3`, выделенный фон `#eef4ff`, текст выбранного `#1d3f86` |
| Успех | фон `#ecfdf3`, текст `#1f6b43` |
| Внимание, «Изменена», синтетика | фон `#fff4e5`, текст `#8a4b00` |
| Ошибка, блокировка | фон `#fef3f2`, рамка `#f2b8b5`, текст `#a32935` |
| Рамка полей, флажков, переключателей | `#7a8d9b` (не светлее: контраст ≥ 3:1, P1-11F); в ранних макетах `#98a2b3` — исправить при следующей правке генератора |
| Недоступное | фон `#f2f4f7`, текст `#98a2b3` |
| Нейтральная плашка | фон `#f2f4f7`, текст `#344054` |

Это цвета проверочных макетов, а не runtime tokens: реализация берёт semantic tokens P1-00C.

## Пиктограммы

Только Tabler Icons outline (O-024). Нужная иконка скачивается с закреплённого релиза (сейчас `v3.49.0`, commit в `assets/icons/THIRD_PARTY.md`) в `assets/icons/tabler/outline/`, проверяется на отсутствие скриптов и внешних ссылок, записывается в реестр `THIRD_PARTY.md`, а в макет встраивается как `<symbol>` с исходными path. Самодельные значки и символы-заменители (`⋮⋮`, `↑`, `✕`, `○`) запрещены; переключатели и флажки рисуются как элементы формы.

## Папки и имена

`docs/design/assets/<NN-раздел>/<NN-MM>_<задача>_<имя>.svg`; таблица разделов — в [`P1-01-svg-index.md`](P1-01-svg-index.md). Новый макет сразу добавляется в индекс и в спецификацию своей задачи. Ссылка на логотип из подпапки — `../../../../assets/brand/icons/stezhik-head-1024.png`.

- `connections_svg.py` — макеты `05-01`…`05-04` «Подключения».
- `settings_yaml_svg.py` — макет `06-02` «Настройки → Общие» (P1-09B); помощники берёт из `publication_svg.py`.
- `about_svg.py` — макет `06-04` «О программе и лицензии» (P1-12); помощники берёт из `publication_svg.py`.
- `editor_svg.py` — макеты `12-01`…`12-04` «Редактор страницы» (P1-04A–E); помощники берёт из `publication_svg.py`.
- `synthetic_svg.py` — макет `12-06` «Предпросмотр с синтетическими данными» (P1-04I); помощники берёт из `publication_svg.py` и `bindings_svg.py`.
- `motion_svg.py` — раскадровка `00-02` «Стежик: состояния и движение» (P1-10); помощники берёт из `publication_svg.py`.
- `export_svg.py` — макеты `13-01`…`13-04` «Экспорт» (P1-07); помощники берёт из `publication_svg.py`, `bindings_svg.py` и `import_library_svg.py`.
- `settings_rest_svg.py` — макеты `06-03`, `06-05`, `06-06` «Настройки» (P1-09D/G); меню как в `settings_yaml_svg.py`, помощники из `publication_svg.py`.
- `bindings_svg.py` — макеты `09-01`…`09-07` «Привязки» (P1-05).
- `import_library_svg.py` — макеты P1-03: `02-01`…`02-03`, `03-01`…`03-03`, `04-01`, `07-02`; общие помощники берёт из `publication_svg.py`.

Запуск из корня репозитория: `.venv/Scripts/python.exe docs/design/tools/structure_svg.py`. Новые экраны с повторяющимися элементами лучше делать генератором на `appbar.py`, чем копировать разметку.

## Проверка перед сдачей

1. XML валиден: `.venv/Scripts/python.exe -c "import sys,xml.etree.ElementTree as E; E.parse(sys.argv[1])" <файл>`.
2. Рендер в headless Edge или Chrome (`--headless=new --window-size=1600,1000 --screenshot=<png>`) просмотрен: текст не выходит за рамки и не перекрывается. PNG хранится вне репозитория.
3. Латиница в видимом тексте — только идентификаторы API, ключи, коды, имя продукта и пользовательские данные.
4. Новые строки интерфейса добавлены в P1-00F (EN и RU) или в таблицу message IDs своей спецификации.
