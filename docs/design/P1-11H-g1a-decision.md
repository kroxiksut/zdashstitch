## 4. Рекомендация

Принять G1a при решениях D1–D7 по рекомендации. Приёмка G1a означает, что дизайн P2–P3 однозначен для реализации; она не означает, что функции P2–P3 реализованы. Проход G1b (все UC-01—UC-10, P1-04, P1-07, остальной P1-09, P1-10) выполняется отдельно.
