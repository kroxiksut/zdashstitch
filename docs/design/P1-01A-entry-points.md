# P1-01A — Пользователи, контексты и точки входа

Статус: draft для приёмки владельцем. Это design specification, не реализованный экран.

Проверочный макет: [`assets/P1-01A-start.svg`](assets/P1-01A-start.svg). Макет выполнен только в светлой теме и содержит один экран.

## 1. Решение

Пользователь работает с теми же сущностями, что и в Zabbix: **панель → страница → виджет** (официальная русская локализация Zabbix 7.4). Слова «проект» в интерфейсе нет (O-025, уточнение 24.10.2026). Стартовый экран сразу предлагает два равноправных пути:

1. **Панели в Zabbix** — выбрать глобальную панель на сервере и заменить узел сети, клонировать панель или взять страницу. Это основной сценарий первых этапов MVP (P2, P3).
2. **Локальные черновики** — создать панель или страницу, собрать панель из готовых страниц, взять одну страницу без всей панели, импортировать файлы и опубликовать позже (O-027, [`P1-01I-page-flows.md`](P1-01I-page-flows.md)).

Локальный черновик называется своей сущностью («Панель» или «Страница») и всегда показывает происхождение: «Локальная» (создана здесь или импортирована из файла) либо «Копия с сервера» (рабочая копия снимка панели или страницы). Источник и назначение независимы: страницу можно взять из одной панели и добавить в другую через явное действие «Добавить страницу в панель».

`Prod` и `Pilot` не являются типами объектов. Такие слова могут встречаться только в пользовательских именах подключений, групп узлов сети или панелей и не влияют на навигацию.

## 2. Entry points

| Точка входа | Цель пользователя | Требуемый контекст | Доступно offline | Результат | Следующий осмысленный шаг |
|---|---|---|---|---|---|
| Выбрать панель в Zabbix | заменить узел сети, клонировать панель или взять страницу | подключение (по умолчанию `read_only`) | нет | снимок и копия с сервера выбранной панели или страницы (P1-03, P2-05) | ReplaceHost (P1-05/P1-08), Clone (P1-05) либо работа со страницей |
| Подключиться к Zabbix / сменить подключение | выбрать или создать профиль | профиль | нет | маршрут P1-02A | вернуться к выбору панели |
| Создать панель | подготовить новую панель целиком | имя; подключение не требуется | да | локальная панель с одной пустой страницей | добавить страницы и виджеты, затем «Создать панель» на сервере |
| Создать страницу | подготовить страницу для новой или существующей панели | имя; подключение не требуется | да | локальная страница | добавить виджеты, затем «Добавить страницу в панель» |
| Собрать из страниц | новая панель из готовых страниц других панелей, черновиков и файлов коллег | ничего; источники выбираются на экране сборки | да (страницы из Zabbix — при подключении) | локальная панель, собранная из страниц (P1-01I) | порядок и свойства панели, привязки по страницам, затем «Создать панель» |
| Взять страницу | одна страница без всей панели | панель в Zabbix, файл или библиотека | да для файла и библиотеки | черновик страницы | «Добавить страницу в панель» или использовать в сборке |
| Импорт файлов | принести экспорт шаблонов, файл панели или файл страницы | один или несколько недоверенных файлов (YAML, JSON, XML, ZIP) | да | маршрут P1-03A; черновик создаётся только после успешной проверки | проверить состав импорта |
| Недавнее | быстро продолжить | сохранённый черновик с типом и происхождением | да | рабочая область этого черновика | восстановить раздел; при недоступности предложить найти объект, тип не менять автоматически |
| Все локальные черновики | найти и открыть сохранённую панель или страницу | хранилище приложения (O-018) | да | список с фильтром по типу и происхождению | открыть рабочую область |
| Незавершённая операция | безопасно разобрать запись журнала O-018 | durable journal entry | да для просмотра | recovery до остальных действий записи | reconciliation; повторная отправка запрещена |

«Открыть» всегда относится к черновикам в хранилище приложения. Файл с диска всегда приносится через «Импорт файлов»: так у пользователя один способ работы с файлами.

## 3. Выбор файлов

По O-023 основной путь — нативный диалог, запущенный локальным процессом защищённым запросом. UI получает непрозрачный идентификатор выбора и отображаемое имя; полный путь браузеру не передаётся. Пока диалог открыт, экран показывает ожидание, отмену и загрузку через браузер. Одновременно допустим один диалог. Недоступность диалога, истечение времени и отмена пользователем — разные состояния (`dialog_unavailable`, `dialog_timeout`, `user_cancelled`, `dialog_busy`).

Загрузка через браузер принимает только содержимое файла и не обещает доступ к исходному пути или запись обратно.

## 4. Приоритет и композиция стартового экрана

1. Recovery banner O-018, если есть, — перед всеми действиями; блокирует новые записи в ту же цель, но не чтение локальных данных.
2. Заголовок и одна строка о том, что локальная работа не требует подключения, а запись на сервер идёт только через проверенный план.
3. Две равноправные карточки: «Панели в Zabbix» (единственное основное действие экрана — «Выбрать панель»; без подключения — «Подключиться к Zabbix») и «Локальные черновики» с плитками «Панель» («Создать панель», «Собрать из страниц») и «Страница» («Создать страницу», «Взять страницу»), ниже — «Импорт файлов».
4. «Недавнее» — не более пяти записей с типом («Панель»/«Страница»), происхождением («Локальная»/«Копия с сервера»), состоянием и временем; ссылка «Все локальные черновики».
5. Режим подключения постоянно виден в верхней строке.

Действия называются пользовательскими формулировками; внутренние имена (`CreateDashboard`, `AppendPage`) в интерфейсе не показываются, только в технических сведениях.

## 5. Message IDs

Используются утверждённые `startup.title`, `startup.subtitle`, `startup.action.import_files`, `startup.action.connect`, `startup.recovery.found`, `session.bootstrap.invalid`, `session.expired.*` и новые ID из P1-00F (`startup.server.*`, `startup.local.*`, `startup.action.choose_dashboard`, `startup.action.new_dashboard`, `startup.action.new_page`, `startup.recent.*`, `object.kind.*`, `object.origin.*`, `intent.*`).

Для P1-01 дополнительно:

| ID | EN source | RU |
|---|---|---|
| `startup.dialog.waiting` | A system dialog is open | Открыт системный диалог |

| `startup.draft.missing` | This draft is no longer available in local storage. | Черновик больше недоступен в локальном хранилище. |

## 6. Acceptance checks

- Новый пользователь может начать offline без профиля Zabbix.
- Со стартового экрана одним действием доступен выбор панели на сервере (основной сценарий P2/P3).
- Со стартового экрана доступны «Собрать из страниц» и «Взять страницу» (O-027).
- В интерфейсе нет слова «проект»; черновик всегда показывает тип («Панель»/«Страница») и происхождение.
- Термины соответствуют официальной русской локализации Zabbix 7.4: панель, страница, виджет, узел сети, элемент данных.
- Страница может иметь исходную и другую целевую панель; UI не сливает их в одну identity.
- Возвращающийся пользователь может открыть черновик даже при недоступном сохранённом подключении.
- Нативный диалог и загрузка через браузер не передают браузеру полный локальный путь.
- Ни один элемент не трактует `Prod`/`Pilot` как тип объекта.
- Стартовый экран не содержит полей endpoint/auth — это P1-02; проверка файлов и область импорта — P1-03.
