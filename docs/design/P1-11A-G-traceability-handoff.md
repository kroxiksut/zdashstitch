# P1-11A и P1-11G — реестр артефактов, трассировка и handoff реализации (G1a)

Статус: проход G1a принят владельцем 25.10.2026 (решения D1—D7 по рекомендации P1-11H). Версия: **G1a v1, 25.10.2026**. Область прохода G1a (O-020): сценарии P2—P3 — UC-01, UC-02, UC-08, UC-09, UC-10, общие потоки подключения, копии с сервера и публикации. Всё, что относится к G1b (UC-03—UC-07, редактор P1-04, экспорт P1-07, профили P1-06, motion P1-10, остальная часть P1-09), помечено «G1b» и здесь не проектируется.

Документ не вводит новых требований и экранов. Он связывает принятые артефакты с задачами реализации и фиксирует пробелы. Неоднозначный контракт помечен «вернуть владельцу P1-задачи» и не решается здесь.

Источники: `docs/product/USE_CASES.md`, `docs/product/PROJECT_GOALS.md`, `docs/MVP_TRACEABILITY.md`, `AGENTS.md`, ADR-001—013, `docs/architecture/*`, `TASKS_RU.md` (P2, P3), все документы и макеты `docs/design/`.

## 3. Пакеты реализации (P1-11G)

Общие правила для всех пакетов:

- UI вызывает только API локального приложения; JSON-RPC Zabbix — только в процессе Rust (адаптер 7.4). Все изменяющие запросы идут через слой P2-SEC-01 (сессия, Origin/Host, CSRF).
- Ответы API содержат коды и параметры (`{code, params}`), не готовый текст; тексты — каталоги `lang/en`, `lang/ru` (P2-00A). Сообщения с `{…, plural, …}` требуют ICU plural в рантайме (P2-00-FIX).
- Компоненты — только из P1-00D/P2-00C, цвета — только semantic tokens P1-00C; `{@html}` для данных запрещён.
- Секреты: только в процессе Rust или системном хранилище по выбору; не в YAML, URL, browser storage, журналах и отчётах.
- `VerifiedPlan` не покидает процесс; UI видит только `plan_id` и данные предпросмотра (P1-08F).
- Состояния загрузки, пустоты, ошибки — по P1-00E; задержки — по P1-IN-06.
- Ещё не реализованные разделы G1b (редактор, «Проверки», экспорт) видны недоступными с подсказкой «Появится позже» (P1-01H §6).
