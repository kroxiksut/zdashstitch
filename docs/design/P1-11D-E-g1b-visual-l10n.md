## 4. Сообщения и термины

**Дубль ID.** `publication.action.confirm_write`: в P1-08 — «Записать в Zabbix» (кнопка в диалоге), в P1-00F §8 — «Подтвердить запись…» (кнопка шага 4, открывающая диалог). Исправлено в P1-00F: ID §8 переименован в `publication.action.open_confirm`.

**Плюрализация.**

| ID | Источник | Проблема | Исправление |
|---|---|---|---|
| `export.result.accepted_warnings` | P1-07, строка 217 | RU только `one/other` | `{count, plural, one {Принятое предупреждение: #} few {Принятые предупреждения: #} many {Принятых предупреждений: #} other {Принятые предупреждения: #}}` |
| `checks.progress` | P1-04F-G, строка 242 | «из {total} объектов» без плюрализации («из 1 объектов», «из 21 объектов») | `{total, plural, one {Проверка… {done} из # объекта} other {Проверка… {done} из # объектов}}` |
| `publication.diff.page_summary` | P1-08, строка 274 | «из {total} виджетов изменены» | плюрализация по `total` («из 1 виджета», «из 5 виджетов») |

**Глоссарий.** `settings.storage.state.read_only` (P1-09D-H, строка 249) — «Только чтение: нет прав на запись» для папки хранилища нарушает правило P1-00E §12 («Только чтение» — только режим подключения и права доступа Zabbix). Предложение: «Запись запрещена: нет прав» / «Writing is not allowed: no permission».

- Открытые пункты G1a имеют актуальный статус.
