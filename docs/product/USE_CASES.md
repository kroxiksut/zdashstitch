# Сквозные сценарии для приёмки и проектирования

Каждый сценарий — поведение **целевого** приложения, пока не реализован. Нельзя заменять ими контрактные испытания Zabbix 7.4.

| ID | Исходные условия | Действия | Ожидаемый результат |
|---|---|---|---|
| UC-01 | Есть Zabbix 7.4 и тестовая панель с несколькими виджетами | ReplaceHost старый → новый | Заменены только разрешённые ссылки; остальные виджеты/права сохранены, неизвестные явно отображены |
| UC-02 | В одном Zabbix 7.4 есть Prod-панель со страницами PostgreSQL, OS и отдельные группы узлов Prod/Pilot | CloneDashboard → Pilot, явно задать соответствия целевым хостам | Создана **отдельная приватная** панель в том же подключении; оригинал не изменён |
| UC-03 | Файлы нескольких пользовательских шаблонов | Офлайн-импорт YAML/JSON/XML → DB Pilot | На странице ClickHouse доступны метрики CH/Keeper/HAProxy/Linux без сервера |
| UC-04 | Есть готовый переносимый пакет и тестовая 7.4 | Назначить хосты → CreateDashboard | Только реальные источники, соответствия проверены; макет укладывается в сетку |
| UC-05 | На сервере уже есть DB Pilot с PostgreSQL и OS | AppendPage ClickHouse | Старые страницы/виджеты не меняются |
| UC-06 | На странице уже есть пользовательские виджеты | AppendWidgets | Неподтверждённая возможность сохранения неизвестных полей блокирует опасную запись |
| UC-07 | Проект создан вне рабочего контура | Перенести project.yaml+metrics через ZIP | Без локальных `hostid/itemid`, токенов, состояний публикации; не заявлять полную обезличенность свободного текста |
| UC-08 | Виджет зависит от LLD-прототипа | Назначить хост без найденного экземпляра | Статус unresolved, требуется выбор, никакого выдуманного itemid |
| UC-09 | Панель изменилась после предпросмотра | Нажать подтверждение публикации | Исходный план инвалидируется; требуется новый preview |
| UC-10 | Сеть оборвалась после отправки | Повторить/проверить результат | Не повторять запись вслепую; читать состояние и выяснять outcome |

Любой кодовый агент использует это как сквозную матрицу сценариев; сами тестовые данные должны быть синтетическими и не содержать внутренней инфраструктуры.
