# ADR-014 — Переносимые профили оформления и заготовки виджетов

**Принято владельцем** по O-012, P1-06H Q1 и OQ-P4-05 (уточнения от 21.11.2026).

- `zdashstitch.style-profile/v1` и `zdashstitch.widget-blueprint/v1` обмениваются отдельными файлами YAML. Форматы `project/v1`, `project/v2` и состав DATA-ONLY ZIP сохраняются. Проект хранит значения полей виджетов, применение профиля копирует значения. Сведения о применении хранятся локально.
- Профиль содержит только разрешённые визуальные поля `item` и `svggraph`. Пустой цвет восстанавливает умолчание только у поля с независимо подтверждённым поведением в заявленном адаптере. Прочие цвета имеют шесть шестнадцатеричных символов в верхнем регистре.
- Заготовка описывает один виджет `item` или `svggraph`, размер и параметры, без размещения. Ссылка на метрику задаёт параметр метрики, параметр роли и явный выбор узла. У роли с несколькими узлами одиночная ссылка выбирает именованный слот. Привязка выполняется при вставке.
- Данные исключают идентификаторы подключений, серверов, панелей, шаблонов, узлов сети и элементов данных, ключи элементов данных, буквальные маски, ссылки `reference` и `*._reference`, переопределения `or.*` и неизвестные поля. Свободный текст при внешнем обмене требует проверки пользователя.
- Допуск версии формата устанавливает возможность прочитать файл. Направление применения, совместимость поля и допуск записи проверяются независимо для точной версии Zabbix. Лабораторное подтверждение одного поля или формы виджета не распространяется на остальные.
